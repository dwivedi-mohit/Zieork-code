# 🤖 Zieork Project Instructions & Operational Rules (AGENTS.md)

## 1. Code Standards
- Write self-contained, elegant Python code with standard library support.
- Never use deprecated methods or unverified third-party libraries.
- Include docstrings and type hints for all public methods.

## 2. Test Verification
- Always write unit tests for new modules in `tests/`.
- Verify all tests pass with zero warnings before declaring a task complete.

## 3. Git & Worktrees
- Use Conventional Commits (`feat:`, `fix:`, `refactor:`, `test:`).
- Keep diffs minimal, clean, and well-documented.

## 4. Safety & Sandbox
- Never delete workspace files without user confirmation.
- Execute terminal commands inside the sandboxed environment.
